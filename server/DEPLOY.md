# ขึ้นเว็บบนเซิร์ฟเวอร์โรงเรียน

## สิ่งที่ต้องถามครูผู้ดูแลเซิร์ฟเวอร์ก่อน

1. เว็บจะอยู่ที่ URL อะไร เช่น `http://www.โรงเรียน.ac.th/school-info/`
   - ถ้าชื่อโฟลเดอร์ไม่ใช่ `school-info` ให้แก้บรรทัด `set "APP=school-info"` ใน `deploy.bat`
2. อัปโหลดไฟล์ด้วยวิธีไหน (คัดลอกผ่านแฟลชไดรฟ์ / FTP / แชร์โฟลเดอร์)
3. ชื่อฐานข้อมูล ชื่อผู้ใช้ และรหัสผ่าน MySQL ที่ใช้ได้ และเข้า phpMyAdmin ได้ที่ไหน
4. เซิร์ฟเวอร์เป็น Apache และอนุญาตไฟล์ `.htaccess` หรือไม่ (`AllowOverride All` และเปิด `mod_rewrite`)

## ติดตั้งครั้งแรก

1. **สร้างชุดไฟล์:** ดับเบิลคลิก `deploy.bat` ในโฟลเดอร์โปรเจกต์ แล้วรอจนขึ้น "เสร็จแล้ว"
   - `deploy\school-info\` คือหน้าเว็บ + API อัปโหลดทั้งโฟลเดอร์นี้
   - `deploy\database\install.sql` คือไฟล์สร้างฐานข้อมูล
2. **ฐานข้อมูล:** ใน phpMyAdmin ของเซิร์ฟเวอร์
   1. สร้างฐานข้อมูล ตั้ง Collation เป็น `utf8mb4_unicode_ci` (ถ้าครูสร้างไว้ให้แล้ว ข้ามได้)
   2. คลิกที่ฐานข้อมูลนั้น → แท็บ Import → เลือก `install.sql` → Import
   3. **ไม่ต้อง** import ไฟล์ข้อมูลตัวอย่าง (sample-data)
3. **อัปโหลด:** คัดลอกโฟลเดอร์ `deploy\school-info` ไปวางในที่เก็บเว็บของเซิร์ฟเวอร์ (เช่น `htdocs\` หรือ `public_html\`)
   - ต้องมีไฟล์ซ่อน `.htaccess` ติดไปด้วย 2 ไฟล์ (ที่โฟลเดอร์หลัก และใน `uploads`)
4. **ตั้งค่าฐานข้อมูล:** บนเซิร์ฟเวอร์ ในโฟลเดอร์ `api\`
   คัดลอก `config.example.php` เป็น `config.php` แล้วแก้ 4 บรรทัด `DB_HOST`, `DB_NAME`, `DB_USER`, `DB_PASS`
5. **ตรวจความพร้อม:** เปิด `http://…/school-info/api/check.php`
   ต้องขึ้น ✅ ทุกข้อ ยกเว้น "สร้างผู้ดูแลระบบแล้ว" (ทำในข้อถัดไป) ถ้ามี ❌ ให้ทำตามคำแนะนำสีส้ม
6. **สร้างผู้ดูแลระบบทันที:** เปิด `http://…/school-info/login` จะขึ้นหน้า "ตั้งค่าครั้งแรก"
   ⚠ ทำทันทีหลังอัปโหลด เพราะหน้านี้เปิดให้ทุกคนจนกว่าจะมีผู้ดูแลคนแรก
7. แท็บ "ผู้ใช้" → สร้างบัญชีให้ 4 ฝ่าย, แท็บ "ปีการศึกษา" → ตั้งภาคเรียนปัจจุบัน
8. ลองกด F5 ในหน้าเล่ม ถ้าขึ้น 404 แปลว่าเซิร์ฟเวอร์ไม่อ่าน `.htaccess` ให้ครูผู้ดูแลเปิด `AllowOverride All` และ `mod_rewrite`

## อัปเดตเว็บครั้งต่อไป

1. ก่อนอัปเดต **สำรองข้อมูล:** phpMyAdmin → Export ฐานข้อมูล และคัดลอกโฟลเดอร์ `uploads` เก็บไว้
2. ดับเบิลคลิก `deploy.bat`
3. คัดลอก `deploy\school-info` ไป **วางทับ** ของเดิมบนเซิร์ฟเวอร์ได้เลย
   - `api\config.php` และรูปใน `uploads` ไม่ถูกทับ เพราะไม่มีอยู่ในชุดไฟล์
4. ถ้าครั้งนั้นมีการเปลี่ยนฐานข้อมูล จะมีไฟล์ SQL สำหรับอัปเกรดแยกมาให้ import เฉพาะไฟล์นั้น
   - **ห้าม** import `install.sql` ซ้ำในฐานข้อมูลที่ใช้งานอยู่

## ห้ามทำ

- ห้ามเอา `config.php` ของเครื่องตัวเองขึ้นเซิร์ฟเวอร์ หรือขึ้น git
- ห้ามลบหรือวางทับโฟลเดอร์ `uploads` บนเซิร์ฟเวอร์ (รูปของทุกฝ่ายอยู่ในนั้น)
- ห้าม import ข้อมูลตัวอย่างบนเซิร์ฟเวอร์จริง
